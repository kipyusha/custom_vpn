# CustomVPN 0.2.1

Небольшое обновление страницы «Правила»: при попытке добавить уже существующее правило приложение теперь показывает, где оно задано, а панель вкладок и кнопка добавления сайта всегда остаются под рукой.

## Главное

### Переход к уже добавленному правилу

- При добавлении дубля сайта, домена, поддомена или процесса показывается уведомление и автоматически открывается страница «Правила».
- Нужная запись прокручивается в центр и подсвечивается.
- Для дубля поддомена автоматически раскрывается список доменов нужного сайта.
- Окно добавления сайта закрывается при дубле, даже если ошибку вернул бэкенд.

### Удобная панель правил

- Вкладки «Сайты», «Домены», «Приложения» и кнопка «Добавить сайт» объединены в одну панель.
- При прокрутке страницы панель закрепляется сверху, поэтому переключение разделов и добавление сайта доступны в любой момент.
- Убрана лишняя пустая полоса над закреплённой панелью.

## Обновление

- Встроенное обновление: «Настройки» → «Проверить обновления».
- Или скачайте установщик либо портативный архив из Assets этого релиза.
- Поддерживаются Windows 10/11 с WebView2.

## Ограничения

- TUN-режим по-прежнему не входит в эту версию: приложение использует системный proxy и правила sing-box.
