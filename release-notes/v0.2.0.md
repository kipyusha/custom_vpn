# CustomVPN 0.2.0

Крупное обновление CustomVPN: полностью переработанный интерфейс, новый экран мониторинга и режим обучения, который помогает находить CDN-домены для сайтов без ручного поиска.

## Главное

### Новый интерфейс

- Полностью новый тёмный интерфейс с собственным titlebar, боковым меню и статусной строкой.
- Переработан главный экран: крупная кнопка подключения, статус профиля, время сессии и график скорости.
- Улучшена адаптивность: интерфейс корректно перестраивается на узких окнах.
- Добавлены аккуратные анимации, свечение активного подключения и плавные hover-эффекты.
- Единый стиль для страниц «Главная», «Правила», «Монитор» и «Настройки».

### Режим обучения доменов

- На странице «Правила» у каждого сайта появилась кнопка «Найти домены».
- CustomVPN наблюдает реальные соединения браузера или приложения в течение 1–2 минут.
- Найденные домены группируются по основному домену, показываются процесс, количество соединений и объём трафика.
- Поддерживается ручной выбор: можно снять галочки с рекламных и лишних доменов перед добавлением.
- Уже покрытые домены сайта, поддомены, IP-адреса и локальные адреса исключаются автоматически.
- Выбранные домены добавляются одним действием и одним перезапуском sing-box.
- Для добавления используется существующая модель правил, поэтому новые домены сразу учитываются в маршрутизации.

### Новые карточки сайтов

- Карточки сайтов получили автоматическую загрузку favicon: сначала с самого сайта, затем через резервный сервис, затем в виде цветной буквы.
- Добавлен режим скрытия: название, адрес, логотип и список доменов размываются.
- Список дополнительных доменов стал понятнее: отображаются названия, количество и быстрый переход к управлению.
- Управление сайтом, поддоменами и включением в VPN собрано в одном месте.

### Монитор соединений

- Новый экран с активными и завершёнными соединениями.
- Поиск по домену и процессу.
- Фильтр «только через VPN».
- Группировка по хостам, отображение направления, процесса, объёма трафика и времени активности.
- Очистка журнала соединений без перезапуска VPN.

### Настройки и обновления

- Переработан экран настроек с профилем, версией приложения, статусом прав администратора и доступностью sing-box.
- Проверка и установка обновлений через встроенный updater.
- Управление proxy-переменными для OpenCode Desktop.
- Очистка оставшихся процессов sing-box.
- Добавлены информативные состояния и подсказки для ошибок.

## Улучшения

- Переработан график скорости: отдельные линии загрузки и отгрузки, диапазоны 1/5/30 минут, компактная легенда.
- Добавлена плавная смена состояний подключения и более выразительная активная кнопка.
- Улучшена читаемость вторичного текста и мелких подписей.
- Добавлена поддержка скрытия данных на главной панели правил и на странице «Правила».
- Улучшены пустые состояния, баннеры ошибок и уведомления.
- Обновлены скрипты запуска и упаковки портативной версии.

## Технические изменения

- Интерфейс разбит на отдельные компоненты и страницы.
- Добавлена batch-команда `add_site_subdomains`: несколько доменов сохраняются за один проход и один перезапуск sing-box.
- Добавлена группировка хостов по registrable domain с учётом распространённых составных зон.
- Добавлен сбор кандидатов из существующего журнала соединений Clash API.
- Добавлена автоматическая загрузка favicon с fallback-цепочкой.
- Улучшена обработка состояния окна, трея и single-instance запуска.
- Сохранены профиль, правила и пользовательские сайты при обновлении.

## Обновление

- Встроенное обновление: «Настройки» → «Проверить обновления».
- Или скачайте установщик либо портативный архив из Assets этого релиза.
- Поддерживаются Windows 10/11 с WebView2.

## Ограничения

- Определение связанных доменов основано на сетевых соединениях, поэтому в список могут попадать рекламные и общие CDN-домены. Добавление всегда требует подтверждения пользователя.
- TUN-режим не входит в версию 0.2.0: приложение использует системный proxy и правила sing-box.
- Для работы режима обучения VPN должен быть подключён.
